## AWS network design implementation scope

- Reviewed official [VPC routing and private-workload guidance](https://docs.aws.amazon.com/vpc/latest/userguide/vpc-example-private-subnets-nat.html), [subnet types](https://docs.aws.amazon.com/vpc/latest/userguide/configure-subnets.html), [Fargate networking](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/fargate-task-networking.html) and [ALB subnet requirements](https://docs.aws.amazon.com/elasticloadbalancing/latest/application/application-load-balancers.html).
- Public/private refers to subnet routing within a regional VPC. Public ingress, private compute and isolated data boundaries are proposed only for applicable service types. Ambiguous static-hosting/container candidates, internal load balancer schemes and Lambda attachment remain unresolved rather than being silently placed in private subnets.
- Managed service APIs and static delivery are drawn outside subnet boundaries. Multi-region views use separate regional VPC boundaries. Standard regional ALB designs include at least two availability-zone subnets even when application capacity requests a single zone; this is guidance, not a validated customer network.
- Network preview can be opened before targets are known. It labels the region and targets unconfirmed, shows reference boundaries, and does not invent traffic numbers, CIDRs, ports, costs, actual replicas or cloud resources. Requirement entry and an infrastructure review remain mandatory for approval and deployment.
- Logical layers are balanced across the workspace. A component's immediate connections can be focused without deleting hidden nodes. Default cloud zoom preserves readability on small canvases; explicit Fit remains an overview control. Only the canvas and assistant scroll; the document remains a fixed tool workspace.
- Frontend production build/type/lint checks and Python compilation passed. No automated test suite was run. AWS findings refresh and real account network/provisioning behavior could not be verified because a customer observer account and provisioning worker are not configured.
